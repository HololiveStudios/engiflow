01 — INFRAESTRUTURA

Stack e Hospedagem

Duas zonas: Cloudflare (edge-native, zero ops) e VPS apenas para o bridge WhatsApp persistente.

☁ Cloudflare Pages

FRONTEND — REACT + TS
  • Dashboard interno (painel operacional)
  • Portal do cliente (subdomínio separado)
  • Deploy automático / CDN global
CF PAGES

⚡ Cloudflare Workers

API — TYPESCRIPT EDGE
  • API REST por módulo
  • JWT + RBAC multi-papel
  • Scheduled Worker: cron de vencimentos
  • Geração de PDF com PDFLib WASM
  • Integração nativa D1 / KV / R2
CF WORKERS

🟣 VPS Dedicado

WHATSAPP BRIDGE — GO
  • Go + whatsmeow — cliente WA Web
  • Processo contínuo (sessão persistente)
  • Recebe mensagem → POST para Worker API
  • SQLite local para sessão WA
  • ~R$40/mês, 2GB RAM suficiente
VPS — GO

🗄 Cloudflare D1 + R2 + KV

BANCO · STORAGE · CACHE
  • D1: banco principal (SQLite managed)
  • R2: certificados PDF, fotos, documentos
  • KV: sessões JWT, tokens de portal
CF D1 · R2 · KV
Por que D1? Zero ops, acesso direto no Worker, Drizzle ORM para migrations. Para SST B2B, D1 é suficiente.
VPS obrigatório apenas para WA: Workers são stateless — whatsmeow exige processo contínuo. Nada mais roda no VPS.

06 — WHATSAPP

Bridge WhatsApp — Detalhamento

Go + whatsmeow no VPS como processo contínuo. Sem lógica de negócio — apenas recebe/envia e chama a Worker API por HTTPS + HMAC.

01
whatsmeow mantém WebSocket persistente com servidores WA Web.
VPS Go
02
Extrai número, texto, timestamp, tipo. Monta payload JSON.
parser
03
POST para /api/wa/inbound no Worker. HMAC secret compartilhado.
HTTPS
04
Worker busca número no D1. Novo → cria lead (origem: whatsapp). Existente → atualiza contato.
D1
05
Classifica intenção: treinamento / certificado / renovação / humano.
logic
06
Worker envia resposta ao bridge Go. Bridge entrega via whatsmeow.
→ WA
07
Evento logado no D1. Lead novo: alerta CRM. Status: aguardando_humano se necessário.
log
07 — DIFERENCIAIS

O que torna a plataforma inovadora

🔄

Motor de renovação automático

Cron diário, zero intervenção. Cada vencimento detectado gera alerta, proposta e tarefa no comercial.

📊

Radar de conformidade por empresa

Score 0-100 por empresa: treinados, vencidos e pendentes por função e filial. Visível no portal do cliente.

🔍

QR code de verificação

Hash único por certificado. Auditoria escaneia — sem terceiro, sem dependência externa.

⚡

Financeiro por gatilho operacional

Turma realizada → fatura automática. Sem intervenção manual do financeiro.

🌐

Portal self-service

Cliente acessa certificados, vencimentos e histórico. Reduz atendimento manual em 60%+.
